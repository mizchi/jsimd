Scope

SIMD UI requires explicit, immutable dependency arrays and accelerates queue selection. Preact supports dynamic dependencies, components, keyed reconciliation, lifecycle, SSR, and a mature ecosystem. Atomics are excluded from the DOM hot path because DOM mutation remains main-thread-only.
